更新日期：2026-07-31

本文件是唯一的当前任务入口。已完成阶段的详细记录保存在 [历史实施计划](./implementation-plan-history.md)，操作说明保存在 [运维手册](./operations-guide.md) 和 [运维 Runbook](./operations-runbook.md)。

## 1. 当前目标

交付可由个人长期托管、可邀请少量测试用户使用的 Agent 平台测试版。

当前阶段不扩展到正式商业 SaaS，不实现团队计费、复杂组织权限、企业 SSO、多区域部署和大规模运营。先确保单实例在安全、数据、恢复、成本和体验方面可控。

## 10. P50：自动知识库路由精度

目标：将“自动”模式从“存在词面命中就注入”调整为“明确需要资料，或存在强知识锚点且候选足够相关才注入”。优先降低普通写作、计划、编程、页面生成和日常问答的误调用，同时保留用户明确要求知识库以及项目专有问题的召回。

模式语义固定如下，不在实施中临时改变：

- `off`：不探测、不检索、不注入。
- `auto`：精度优先；明确资料意图直接检索，隐式需求必须通过意图门控和强相关性门禁。
- `required`：召回优先；按用户选择主动检索，即使没有强锚点也保留可解释的空结果。

本阶段不引入向量数据库、Embedding、额外模型路由调用或新 Agent 框架，不修改项目空间权限，不让用户反馈自动发布线上策略。

## 13. P51：可观测知识处理与混合检索

目标：将知识库从“上传后直接提取纯文本并固定字符切分”升级为可追踪、可预览、可重跑、可比较的知识处理流水线；先完成结构化解析、结构感知切分和 FTS5/BM25，再引入向量与混合检索。任何升级都必须保持原文件、用户/项目权限和现有词法检索回退能力。

### 13.1 配置边界

配置能力按四层治理，不在 Agent 对话框暴露全部底层参数：

| 层级 | 配置入口 | 允许配置 | 固定边界 |
| --- | --- | --- | --- |
| 普通用户 | 对话框“资料与文件” | `off / auto / required`、通用库/当前项目、精准/均衡/高召回预设 | 不直接设置模型、权重、阈值或向量维度 |
| 知识库管理员 | 上传页与文档详情 | 解析预设、OCR、表格处理、切分预设、重新解析/切分/索引 | 所有变更必须生成版本和处理记录 |
| 平台管理员 | 检索质量与策略中心 | FTS/向量/融合/重排、候选数量、上下文预算、策略评测/发布/回滚 | 不得无评测直接覆盖活动策略 |
| 代码安全边界 | 服务端 | MIME 白名单、大小/页数/解压限制、ACL、超时和参数硬上限 | 不允许通过界面关闭 |

普通用户预设语义：

- `精准`：较少候选和较高相关门槛，优先降低误召回。
- `均衡`：默认策略。
- `高召回`：更多候选，可启用受限查询改写和相邻片段扩展。

### 13.2 文档处理事实源

统一处理链固定为：

```text
原始文件
  → Document IR（标题、段落、列表、表格、页码、工作表、OCR 来源）
  → 可读 Markdown 预览
  → 结构感知 Chunk
  → FTS5/BM25
  → 可选 Embedding
  → 混合召回与重排
```

原文件保持不可变；Document IR 是解析事实源，Markdown 只作为用户预览和诊断视图，不作为唯一结构化存储格式。

更新日期：2026-07-28

本文件是唯一的当前任务入口。已完成阶段的详细记录保存在 [历史实施计划](./implementation-plan-history.md)，操作说明保存在 [运维手册](./operations-guide.md) 和 [运维 Runbook](./operations-runbook.md)。

## 1. 当前目标

交付可由个人长期托管、可邀请少量测试用户使用的 Agent 平台测试版。

当前阶段不扩展到正式商业 SaaS，不实现团队计费、复杂组织权限、企业 SSO、多区域部署和大规模运营。先确保单实例在安全、数据、恢复、成本和体验方面可控。

## 10. P50：自动知识库路由精度

目标：将“自动”模式从“存在词面命中就注入”调整为“明确需要资料，或存在强知识锚点且候选足够相关才注入”。优先降低普通写作、计划、编程、页面生成和日常问答的误调用，同时保留用户明确要求知识库以及项目专有问题的召回。

模式语义固定如下，不在实施中临时改变：

- `off`：不探测、不检索、不注入。
- `auto`：精度优先；明确资料意图直接检索，隐式需求必须通过意图门控和强相关性门禁。
- `required`：召回优先；按用户选择主动检索，即使没有强锚点也保留可解释的空结果。

本阶段不引入向量数据库、Embedding、额外模型路由调用或新 Agent 框架，不修改项目空间权限，不让用户反馈自动发布线上策略。

# Agent_Platform 当前执行计划

更新日期：2026-07-28

本文件是唯一的当前任务入口。已完成阶段的详细记录保存在 [历史实施计划](./implementation-plan-history.md)，操作说明保存在 [运维手册](./operations-guide.md) 和 [运维 Runbook](./operations-runbook.md)。

## 1. 当前目标

交付可由个人长期托管、可邀请少量测试用户使用的 Agent 平台测试版。

当前阶段不扩展到正式商业 SaaS，不实现团队计费、复杂组织权限、企业 SSO、多区域部署和大规模运营。先确保单实例在安全、数据、恢复、成本和体验方面可控。

## 2. 状态口径

- `[x]`：开发与必要验证已完成。
- `[~]`：正在执行，尚未满足全部验收条件。
- `[ ]`：已规划但尚未开始。

- `阻塞发布`：不影响本地开发使用，但未处理前不能开放给外部测试用户。

- `[ ]` P48-0（P1）：冻结 Artifact 契约、API 和数据库迁移。扩展 `mime_type`、`status`、`revision`、`size_bytes`、`updated_at` 和 `content_sha256`；增加 `HTML_ARTIFACT_PREVIEW_ENABLED`，默认只在开发和管理员灰度中启用。
- `[ ]` P48-1（P1）：实现静态 HTML 产物后端。将文件 I/O 从 `app.py` 拆入 Artifact Service；支持 `html` 意图、确认、幂等创建、下载、删除和当前用户鉴权；第一版使用可信模板把 Markdown/结构化结果渲染为完整 HTML，不执行模型生成的任意 JavaScript。
- `[ ]` P48-2（P1）：实现右侧预览 UI。复用现有“对话上下文”栏，增加“预览 / 上下文”切换；HTML/Markdown 点击后预览，XLSX/JSON 保持下载；桌面端使用可关闭右栏，窄屏使用全屏抽屉。
- `[ ]` P48-3（P1）：完成安全与发布门禁。使用带 Bearer Token 的 `fetch` 获取内容并写入 sandboxed `iframe.srcdoc`；禁止脚本、事件属性、表单、顶层导航和未授权子框架；覆盖跨用户访问、路径逃逸、恶意 HTML、重试幂等、移动端、备份恢复和 Docker 冒烟。P48-0 至 P48-3 全部通过后关闭静态预览 MVP。
